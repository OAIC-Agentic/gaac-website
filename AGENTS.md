# Interface design

Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.

- Use hierarchy, spacing, grouping, and active states to make the interface clear.
- Remove copy that repeats a nearby heading, navigation item, count, or status.
- Keep information needed to understand the event or make a decision: tasks, eligibility, timing, scoring, prizes, and registration status.
- Preserve accessible names, keyboard focus, and control labels when simplifying visible text.
